# Tauber — полная версия сайта в стиле Vellum

## Файлы
- `Tauber-Vellum-Full.dc.html` — весь сайт: главная, 10 категорий, ~20 детальных страниц, форма «Подать заявку», боковое меню (бургер слева от логотипа).
- `support.js` — рантайм для `.dc.html`. Не редактировать.
- `assets/` — изображения.
- `Tauber-Vellum-Style.md` — описание стиля (цвета, шрифт Manrope, скругления, отступы, компоненты).

## Запуск
```
npx serve .   # или python -m http.server 8000
```
Открыть `http://localhost:8000/Tauber-Vellum-Full.dc.html`.

## Формат
- Шаблон в `<x-dc>…</x-dc>`: HTML с подстановками `{{ path }}` (только пути, без выражений); циклы `<sc-for>`, условия `<sc-if>`.
- Стили инлайн; hover — атрибут `style-hover`.
- Логика — `<script data-dc-script>`: `class Component extends DCLogic`, данные отдаются из `renderVals()`. Страницы переключаются через `state.page`.

## Главная задача: адаптивность
Сейчас вёрстка фиксирована под ширину 1600px и уменьшается целиком через CSS `zoom` — на телефоне/планшете текст нечитаем.
Нужно:
1. Убрать фиксированную ширину 1600px и zoom-масштабирование.
2. Перевести сетки на `repeat(auto-fit, minmax(min(100%, Npx), 1fr))`, размеры заголовков — на `clamp()`.
3. Меню на узких экранах — только бургер + боковая панель (уже есть).
4. Проверять на 1280, 768 и 390px.
Эталон адаптивной вёрстки в этом же стиле — `Tauber-Home-Vellum`, `Tauber-Filters-Vellum`, `Tauber-FTV-Vellum` (в основном проекте).
