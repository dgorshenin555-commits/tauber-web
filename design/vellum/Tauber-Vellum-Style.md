# Tauber — Vellum Style Reference
> Спокойный монохромный индустриальный стиль: тёплый кремовый фон, тонкая типографика, сильные скругления фото, без теней и акцентных цветов.
> Основа — референс «T1 Energy», адаптированный под Tauber (кириллица, сжатые отступы).

Файлы-эталоны: `Tauber-Home-Vellum.dc.html` (главная), `Tauber-Filters-Vellum.dc.html` (страница раздела).

## Цвета
| Токен | Значение | Роль |
|---|---|---|
| Vellum | `#f0efe9` | Фон страницы |
| Paper White | `#ffffff` | Карточки, панели, кнопки-чипы |
| Sand | `#e8e6de` | Hover карточек, фон-заглушка под фото |
| Carbon Warm | `#322d2a` | Весь текст, линии-разделители, тёмные кнопки, меню, тёмный баннер |
| Onyx | `#0f0e12` | Подвал, затемнение фото |
| Mercury | `#8b8b8b` | Вторичный текст, номера, подписи |
| Muted on dark | `#c9c5bd` | Вторичный текст на тёмном |

Правила: никаких акцентных цветов, градиентов-украшений и теней. Чистый `#000` не использовать. Глубина — только сменой тона (vellum → white → carbon → onyx).

## Типографика
- Шрифт: **Manrope** 300 / 400 (Google Fonts, есть кириллица). Letter-spacing `.01em` везде.
- Display H1: 300, `clamp(40px, 5.2vw, 68px)`, line-height 1.
- H2 секций: 300, `clamp(36px, 3.6vw, 52px)`, line-height 1.
- Цифры (статистика): 300, 52px, line-height 1.
- Подзаголовки / названия карточек и строк: 400, 22px, lh 1.3 (в мелких карточках 16px).
- Текст: 400, 16px, lh 1.4. Мелкий: 14px, lh 1.3–1.4. Подписи: 12px.
- Жирных начертаний нет.

## Метка раздела (фирменный элемент)
Квадрат 4×4px цвета текста + текст 12px, uppercase, letter-spacing `.12em`, gap 10px.
Пример: `■ СОБСТВЕННОЕ ПРОИЗВОДСТВО`. Ставится над каждым H2.

## Скругления
- Большие фото и крупные блоки (hero, баннер, контакты, подбор): `clamp(40px, 5.5vw, 80px)`.
- Карточки продукции: 40–48px (фото внутри — 32–40px).
- Кнопки, чипы, селекты, круглые иконки: 100px.
- Меню-капсула: 16px. Мелкие тёмные плашки: 12px.

## Отступы (сжатая версия)
- Контейнер: max-width 1280px, боковые поля 24px.
- Между секциями: `clamp(36px, 4.5vw, 64px)`.
- Внутри секций: gap 28px; сетки карточек gap 8px; списки преимуществ gap 24px.
- Внутренний padding больших блоков: `clamp(28px, 3.6vw, 48px)`.
- Все сетки адаптивные: `repeat(auto-fit, minmax(min(100%, 420px), 1fr))`.

## Компоненты
- **Шапка:** логотип слева; справа тёмная капсула `#322d2a` (radius 16px), ссылки белые 14px, gap 24px, в одну строку (на узком экране листается вбок); внутри светлая кнопка «Подать заявку».
- **Кнопка основная:** `#322d2a`, белый текст 14px, padding 18px 22px, radius 100px.
- **Кнопка контурная:** прозрачная, 1px `#322d2a`, те же размеры.
- **Hero главной:** фото-слайдер (5 сек) в блоке с большим скруглением, текст белый снизу слева, мягкое затемнение для читаемости; справа тёмная карточка 12px с номером слайда «01 / 04», подписью и круглыми стрелками.
- **Hero раздела:** две колонки — слева метка, H1, описание, кнопки, цифра над линией; справа большое фото с плашкой «■ Производство Tauber».
- **Карточка продукции:** белая, radius 40–48px, padding 8–10px, фото сверху, номер «01», название, описание, круглая стрелка → в контуре.
- **Статистика / преимущества:** линия сверху 1px, номер или цифра, заголовок, серое описание.
- **Аккордеон (Отрасли):** строки с линиями 1px, номер, название 22px, круглая кнопка 40px «+ / −» (открытая — тёмная); раскрывает описание и белые чипы-ссылки. Слева фото, меняется под открытую строку.
- **Подбор:** белый блок, селекты-капсулы на фоне vellum, тёмная кнопка «Подобрать», строка «Рекомендуемое решение».
- **Тёмный баннер:** `#322d2a`, большой radius, H2 белый, контакты, светлая и контурная кнопки.
- **Подвал:** `#0f0e12`, «Tauber» 52px/300, ссылки 14px, нижняя строка 12px серым.

## Изображения
Реальные фото производства и продукции, без фильтров и рамок, `object-fit: cover`. Иконки и эмодзи не используются — только метки-квадраты, стрелки → и +/−.

## Не делать
- Тени, градиенты-украшения, цветные акценты.
- Жирные заголовки.
- Скругления меньше 8px.
- Большие пустые отступы (версия сжатая — держать шаг из раздела «Отступы»).
