# Tauber: рабочая Astro-версия

- Актуальный визуальный эталон: `design/vellum/Tauber-Vellum-Full.dc.html`. При расхождении с `Tauber-Vellum-Style.md` приоритет у HTML. Старый `design/Tauber.dc.html` сохранён для истории.
- Рабочий сайт: `src/`, содержание: `content/`, изображения: `public/images/`. Эталон и его `support.js` не редактировать.
- Сохранять раздельные JSON для совместного наполнения. Не записывать объекты строками и не выдумывать характеристики.
- Стиль: тёплый фон, белые панели, текст #322d2a, локальный Manrope 300/400, крупные скругления, без цветных акцентов и теней.
- Все пути через `put()` с базой `/tauber-web/`. Не использовать масштабирование zoom или фиксированную ширину макета.
- Проверка: `npm run build && npm test`; браузер 1280, 768 и 390 px.
- Работа в отдельных ветках. Main публикуется автоматически через GitHub Pages после слияния PR.
- Отправка запросов пока через почтовый клиент. Настоящие серверные формы требуют отдельной настройки.

## АФТ: решения и ограничения
- `/catalog/fmod/` — раздел «Агрегаты фильтрации топлива (АФТ)»; десять отдельных JSON `content/tovary/aft-*.json`. `/catalog/fmk/` перенаправляется в актуальный раздел.
- Охват: стационарные задачи ГОСТ Р 18.3.01-2023, рисунки Б.1–Б.6 и Б.9–Б.12. Мобильные Б.7/Б.8 и обозначения АФТ-С/АФТ-П отложены. Все направления подтверждены владельцем.
- Страницы АФТ используют `StranicaAft.astro` и четыре вкладки: описание, состав оборудования, технические данные, нормативы и документы. Обязательное механическое оборудование и КИП показаны раздельными таблицами с пунктами ГОСТ Р 18.12.02-2024; условные узлы обозначаются явно. Требования системы не означают, что каждый узел входит в поставляемый агрегат. Числовые параметры определяет проект.
- ПВКЖ, смесь и возвратные потоки описывать отдельно. Возврат слитого топлива допускается после проверки качества и паспортизации.
- Документы поставки перечислять только названиями: паспорта, руководства и другие документы не публиковать. Компоновочные чертежи закрыты; допустимы фотографии и 3D-рендеры. Сейчас предусмотрены подписанные места и упрощённые последовательности операций без размеров.
- Частные исходники в `Данные для анализа АФТ/`, `research_notes/`, `reports/`, `Замечания/` не включать в публичные изменения. ТУ SKID не использовать как основу авиационного ассортимента.
- По уточнению 06.10.2026 опросный лист посетитель прикрепляет вручную в почтовом клиенте; форма готовит письмо, серверной отправки нет. В подвале перечислены все десять категорий продукции.
- Публикация исправлений по «Денис 1.docx» на общей рабочей версии разрешена владельцем 06.10.2026; выполнять через PR и успешные проверки.
- Карта кода: `docs/CODE-MAP.md`. Основания и проверки текущего раздела: `docs/АФТ-источники-и-решения.md`, `docs/АФТ-проверка.md`.
- Уточнение 09.10.2026: согласованы названия «Фильтр грубой очистки (сетчатый)», «Фильтр тонкой очистки (микрофильтр)», «Фильтр-водоотделитель» без синонима в скобках. Не выводить микрофильтр второй строкой того же назначения. У каждой позиции фильтра поле `tonkost` с применимыми пределами и пунктами ГОСТ; предел ступени не подменяет номинал защитной сетки. Для смеси сохранять два последовательных фильтра и запрет водоотделения. Специальный разделитель сред Б.3 сохраняется отдельно.
- По «Денис 2.docx» от 10.10.2026: в разделе АФТ число направлений сопровождается десятью пунктами; на каждой странице агрегата есть горизонтальный список остальных девяти. В публичных названиях и вводных текстах АФТ не использовать «стационарный» и «комплекс». Названия разделов слива-налива и СВКТ согласованы в `content/catalog/categories.json`; сохранять их во всех местах вывода. Ссылки на нормативы ведут на страницы ГАРАНТ в новой вкладке; файлы стандартов в проект не добавлять.

## СВКТ: согласовано 15.10.2026
- Три страницы: `/catalog/zsp1/` — одна точка из подземного резервуара, `/catalog/zsp3/` — три уровня надземного, `/catalog/zspd/` — донный отбор. Категория `/catalog/probe/` сохраняет согласованное название; `/catalog/prb/` — обзор для прежних ссылок.
- Варианты и опции находятся внутри каждой модели; шесть популярных артикулов ЗСП — из каталога, полная матрица по паспорту. ЗСПД: исполнение 1 с колбой, исполнение 2 без колбы. Четырёхточечную систему не показывать. Обозначение трёхточечной — ЗСП3.
- Уточнения владельца имеют приоритет над архивом: температура продукта и среды от −50 до +50 °C для всех моделей; ЗСПД не менее 200 л, только 12Х18Н10Т. ЗСП1: глубина до 8 м по каталогу. Размеры/массу маркировать ориентировочными. ТУ будут уточнены отдельно, пока номера не публиковать.
- Приборы и Deadman — опции, марки не указывать. Резервуарные трубки и плавающее устройство не входят в поставку. Топливо направляется только в дренажную ёмкость; прямой возврат в резервуар/товарную линию запрещён.
- Фото и рендеры позже: пока плейсхолдеры. Чертежи, паспорта, частные исследования не публиковать. НПО «Агрегат» не использовать как основу страниц.
- Заявление о соответствии JIG/IATA дано владельцем; по «Замечания 1.docx» от 19.10.2026 вводную фразу «По заявлению производителя» в публичных текстах убрать. Проверена редакция JIG 2 Issue 13; отдельное подтверждение по пунктам IATA не предоставлено. Не называть это сертификацией.
- Таблицы для утверждения: `docs/СВКТ-варианты-для-утверждения.md`. Страницы используют существующие шаблоны без изменения логики.

- По «Замечания 1.docx», 19.10.2026: панель трёх моделей наполнена назначением каждой; раздел содержит развёрнутые пояснения о целях и видах проб, JIG/IATA и производстве. На ЗСП1 «Точка отбора», ориентировочная масса около 20 кг (уточнение только для ЗСП1); массу ЗСП3 не менять.
