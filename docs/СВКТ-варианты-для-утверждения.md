# СВКТ: варианты для утверждения

15.10.2026. Основа — каталоги TAUBER и паспорт трёхточечной системы; уточнения владельца имеют приоритет. Сайт: три модели ЗСП1, ЗСП3 и ЗСПД. Таблицы ниже отражают данные, выведенные на страницы.

Названия приборов исправлены: ареометр для плотности; марки не указываются. Параметры шкафа, набор приборов и арматура комбинируются по заказу; перечисленные популярные артикулы не ограничивают ассортимент. Коды приборов указываются подряд (123 — все три); можно заказать любой выбранный набор или систему без дополнительных приборов. Суффикс А — Deadman; без него обычная арматура.

## Согласованные ограничения

- ЗСП1: рекомендуемая глубина до 8 м по каталогу.
- Продукт и окружающая среда: от −50 до +50 °C для всех трёх моделей.
- ЗСПД: приёмная ёмкость не менее 200 л, материал только 12Х18Н10Т.
- Приборы и Deadman опциональны; для ЗСПД приборы в колбе относятся к исполнению 1.
- Только отвод в дренажную ёмкость; прямой возврат запрещён.
- Резервуарные трубки и плавающее устройство не входят в поставку.
- Четырёхточечное исполнение исключено. ТУ будут уточнены позднее.
- Фото и рендеры заменены плейсхолдерами; чертежи не публикуются.
