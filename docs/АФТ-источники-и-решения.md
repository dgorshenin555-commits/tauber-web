## Конкурентные ориентиры

Изучены [Деловой союз](https://tzk100.ru/equipment/aft), [НПО Агрегат](https://agregatnpo.ru/production/oborudovanie/agrpt.html) и [Промприбор, АСН-15](https://air.prompribor.ru/produktsiya-i-uslugi/10-sistemy-izmeritelnye-asn-15-sovremennye-agregaty-filtratsii-topliva). В структуре использованы понятные посетителю принципы: выбор по операции, отдельное описание, табличная комплектация и обращение с опросным листом. Чужие числовые характеристики, маркировки и изображения не перенесены в каталог TAUBER.

## Решения владельца

- Все направления TAUBER подтверждены; прежнее содержание заменено.
- Сейчас раскрываются стационарные решения без деления АФТ-С/АФТ-П.
- Источник и получатель среды отражены в месте агрегата в системе и последовательности операций.
- После замечаний Дениса материал разделён на четыре вкладки. В составе оборудования — отдельные таблицы механических узлов и КИП с требованиями и нормативными основаниями. В технических данных — параметры исполнения, нормативные значения для операций/узлов и варианты Заказчика: открытое/закрытое исполнение, резервирование, массовый/объёмный учёт, управление и дополнительные компоненты.
- Комплектация типовой схемы описывает систему: отдельные узлы могут находиться вне поставляемого агрегата. Конкретные параметры фиксируются предложением по объекту.
- Паспорта, руководства и иные документы только перечислены; файлы закрыты. Компоновки закрыты. Фото и 3D-рендеры пока представлены местами для будущих материалов.
- ТУ SKID описывает более широкое применение блочных установок и не задаёт авиационную структуру сайта.
- Отправка обращения и опросного листа пока через почтовый клиент; посетитель добавляет вложение самостоятельно. Упрощённая форма содержит имя/компанию, email и сообщение.

## Уточнения по замечаниям Дениса

- Удалены три общие плашки и повтор назначения, заменены неоднозначные формулировки про требования объекта и резервуарную схему. В подвале перечислены все десять категорий.
- На всех страницах типы фильтров названы по функции; условность каждого узла указана в таблице. Для Б.4 микрофильтрация обязательна по ГОСТ Р 18.12.02-2024, 6.4.2; для Б.11 учёт приёма обязателен по 6.11.2.
- Фильтры-водоотделители не применяются к смеси с ПВКЖ: 6.11.4 и 6.12.4. В Б.6 вариант водоотделения относится только к чистому авиатопливу. Для Б.1–Б.3 водоотделение при приёме условно, но во второй ступени внутрискладской перекачки чистого топлива требуется по 6.14.5.2.
- Общие требования к защите, измерению перепада давления, пробоотбору, дренажу и заземлению распределены по применимым схемам. Нормативные пересказы не обозначаются как дословные цитаты.
- Публичен только перечень обязательной документации с поставкой. Исходный файл замечаний и извлечённые снимки не публикуются.

## Следующее наполнение

Уточнение 09.10.2026: названия фильтров согласованы с владельцем. Фильтр тонкой очистки (микрофильтр) — одна позиция по назначению, а не две автоматически обязательные единицы. Общие «фильтры» из состава ГОСТ нельзя произвольно превращать в дополнительный микрофильтр. Тонкость показана у каждого фильтра: для авиатоплива 15/5/3/3 мкм по операциям 6.14.5.1–6.14.5.4, для ПВКЖ 15/5/3 мкм по 6.15.5.1–6.15.5.3, полнота отсева не менее 97%. Это пределы результата ступени, а не паспортные номиналы каждого элемента. Для защитной сетки перед насосом пункт 4.8 не задаёт отдельного числа; для специального разделителя сред Б.3 отдельное число также не задано. Нормы пригодного авиатоплива не распространяются безусловно на отстой и ОНП. Для Б.11/Б.12 сохранены два последовательных фильтра без выдуманного распределения номиналов между ними. Фильтры ПВКЖ внутри дозирующих систем Б.4/Б.5/Б.12 раскрыты отдельными строками с применимыми режимами.

Потребуются одобренные для публикации фото/3D-рендеры конкретных исполнений. Подтверждённые числовые характеристики можно добавить после выбора реальных моделей. Это не препятствует просмотру текущей структуры.
