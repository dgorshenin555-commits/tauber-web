# Как опубликовать сайт и получить постоянную ссылку

Сайт публикуется сам: при каждом слиянии в `main` он пересобирается и обновляется по постоянному адресу. Отдельная ссылка появляется и у каждого pull request — по ней видно правку до того, как она попадёт на живой сайт.

Подключение делается один раз и требует входа в сервис, поэтому этот шаг за Денисом.

## Почему Cloudflare Pages, а не GitHub Pages

GitHub Pages не публикует приватные репозитории на бесплатном тарифе, а делать проект публичным нельзя: тексты, цены и структура каталога стали бы видны всем. Cloudflare Pages работает с приватными репозиториями бесплатно и даёт то же самое — постоянный адрес плюс ссылку на каждую правку.

## Шаги

1. Открыть `dash.cloudflare.com` и войти — можно через тот же GitHub-аккаунт.
2. В левом меню выбрать **Workers & Pages**, нажать **Create**, перейти на вкладку **Pages**, нажать **Connect to Git**.
3. Разрешить доступ к репозиторию `dgorshenin555-commits/tauber-web`. Если репозитория нет в списке — нажать «Add account» или «Configure repositories» и отметить его.
4. Заполнить настройки сборки:
   - Framework preset: **Astro**
   - Build command: `npm run build`
   - Build output directory: `dist`
   - Переменная окружения `NODE_VERSION` со значением `22`
5. Нажать **Save and Deploy** и подождать пару минут.

Постоянный адрес получится вида `tauber-web.pages.dev`. Его можно открыть с любого устройства.

## Что будет дальше

Слияние в `main` обновляет постоянный адрес автоматически, вручную ничего делать не нужно.

Каждый pull request получает собственную ссылку для просмотра — Cloudflare добавляет её прямо в обсуждение правки. Удобно, когда один поправил характеристики, а второй хочет посмотреть, как это выглядит, прежде чем соглашаться.

Перед публикацией GitHub сам прогоняет проверки: собирает сайт и запускает тесты. Если что-то сломалось, в pull request появится красная отметка, и правку лучше не сливать.

## Свой домен

Когда появится домен (например, `tauber.ru` или поддомен), он подключается в настройках проекта Cloudflare: **Custom domains** → **Set up a domain**. После этого сайт открывается по нему, а адрес `pages.dev` продолжает работать.
