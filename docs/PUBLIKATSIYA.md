# Как опубликован сайт и где его смотреть

Сайт публикуется сам. При каждом слиянии в основную версию GitHub собирает его заново и обновляет по постоянному адресу:

**https://dgorshenin555-commits.github.io/tauber-web/**

Адрес не меняется, открывается с любого устройства, никому заходить в аккаунт не нужно.

## Что для этого настроено

`.github/workflows/publikaciya.yml` — сборка и публикация при изменении основной версии. Ставит зависимости, собирает сайт командой `npm run build`, отдаёт содержимое папки `dist` в GitHub Pages.

`.github/workflows/proverka.yml` — проверка при каждой предложенной правке: собирает сайт и прогоняет тесты. Если что-то сломалось, в правке появится красная отметка.

Обе работают бесплатно, потому что репозиторий публичный.

## Почему репозиторий открыт

GitHub Pages не публикует приватные репозитории на бесплатном тарифе, и автоматические проверки в приватном репозитории тоже упирались в оплату. Решение — открыть репозиторий, как в проекте `funktsiya`.

Что это значит на практике: исходники сайта, тексты, макеты, история правок и переписка в предложенных правках видны всем в интернете. Сам сайт и так публичный, но черновики и незаконченные разделы теперь тоже видны — до того, как вы решите их показать.

Если это перестанет устраивать, вариантов два: GitHub Pro около 4 долларов в месяц (репозиторий снова закрывается, публикация работает) либо перенос публикации на Cloudflare Pages, который умеет и с закрытыми репозиториями.

## Про адрес с подпапкой

Сайт лежит не в корне домена, а в подпапке `/tauber-web/` — так устроен GitHub Pages для обычных репозиториев. Поэтому в настройках сборки (`astro.config.mjs`) указано `base: '/tauber-web'`, а все внутренние ссылки собираются через помощник `src/lib/put.js`.

**Это важно помнить при наполнении:** если написать ссылку прямо как `/catalog/filters/`, она уйдёт в пустоту. Правильно — `put('/catalog/filters/')`. Проверка `tests/bazovyy-put.test.js` следит за этим и не даст ошибиться незаметно.

Когда появится свой домен (например, `tauber.ru`), подпапка исчезнет: в настройках репозитория **Settings → Pages → Custom domain** указывается домен, а в `astro.config.mjs` убирается `base`.

## Если публикация упала

Открой вкладку **Actions** в репозитории, выбери красный запуск и посмотри, на каком шаге он остановился. Текст ошибки пришли мне — разберусь.
