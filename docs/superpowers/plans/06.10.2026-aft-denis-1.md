# Замечания Дениса: реализация и публикация

Основание: пользователь поручил 06.10.2026 применить «Замечания/Денис 1.docx» и выложить результат в общую рабочую версию. Публикация в GitHub Pages разрешена этим поручением; закрытый документ и его изображения остаются локально.

1. Прочитать текст и 11 снимков из DOCX, сопоставить каждый комментарий с интерфейсом.
2. Перепроверить назначение, типы фильтров, механическое оборудование и КИП всех десяти схем. Разделить обязательные требования ГОСТ, условно применимые узлы и пожелания Заказчика.
3. Добавить четыре вкладки: описание, состав, технические данные, нормативы и документы. Состав выводить таблицами с основаниями. Удалить три общих плашки, повторную технологическую задачу и пояснение об отсутствии размеров. Сохранить схему операции и места фото/3D.
4. Заменить неполный подбор формой обращения. Владелец подтвердил отправку через почту: опросный лист прикрепляется вручную в почтовом клиенте. В подвале вывести полный каталог категорий.
5. Проверить сборку, тесты содержания и поведения вкладок, браузер 1280/768/390. Выполнить независимую проверку.
6. Сохранить только публичные изменения в ветке, открыть PR, дождаться проверок и слить его для публикации Pages. Проверить опубликованную версию и передать ссылку пользователю.

Проверяемый результат: десять единообразных страниц с переключением вкладок, конкретными таблицами оборудования/КИП, нормативными ссылками и перечнем поставочных документов без скачивания закрытых файлов. Числовые характеристики изделия не подменяются параметрами из ГОСТ.
