# Мобильная измерительная система АСН-15П1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить в категорию сливо-наливных комплексов карточку и полноценную техническую страницу мобильной измерительной системы АСН-15П1.

**Architecture:** Сохранить существующую data-driven архитектуру Astro: категория получает новую карточку из `content/catalog/auto.json`, а динамический маршрут создаёт товарную страницу из нового JSON. Изображения конкурента не используются; карточка, первый экран и галерея используют два изображения, переданных пользователем.

**Tech Stack:** Astro 7, JSON-контент, Vitest 5, Cheerio.

**Spec:** `docs/superpowers/specs/2026-11-17-asn-15p1-mobile-design.md`

## Global Constraints

- Публичный маршрут: `/catalog/asn-15p1-mobile/` с учётом базового пути `/tauber-web/`.
- Не копировать текст, изображения, логотипы и ссылки конкурента.
- Базовые параметры: DN 80; 15–70 м³/ч; ±0,25%; 600–1200 кг/м³; −40…+40 °C; RS-485; Modbus RTU; фильтрация до 100 мкм.
- Параметры описываются как проектные и подлежащие подтверждению для исполнения TAUBER.
- Использовать только два изображения, переданные пользователем, и не добавлять временные чужие фотографии.

## Review Focus

- Карточка должна вести на реальный статический маршрут, а не на почту или пустую страницу.
- На странице не должны появиться «Промприбор», `prompribor-pk.ru` или чужие изображения.
- Технические значения должны сохранять единицы измерения и не менять смысл исходного описания.
- Оба локальных изображения должны попадать в итоговую сборку без отсутствующих ссылок.
- Добавление товара не должно ломать генерацию и проверку остальных товарных страниц.
