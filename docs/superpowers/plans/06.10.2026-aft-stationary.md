# Реализация стационарного раздела АФТ

> Исполнитель: использовать superpowers:executing-plans. План уточняет уже согласованную реализацию с поправками пользователя; дополнительное ожидание согласования не требуется по прямому поручению работать автономно.

**Цель:** заменить старый раздел полным набором стационарных технологических решений АФТ.
**Архитектура:** сохранить fmod, добавить десять отдельных товарных JSON; расширить существующие шаблоны только для пояснений, упрощённых схем и визуальных мест. Старый fmk перенаправить в новый раздел.
**Стек:** Astro, JSON, Vitest/Cheerio, статическая сборка GitHub Pages.
**Спецификация:** ../specs/06.10.2026-aft-stationary.md

## Общие ограничения
Стиль Vellum, пути через put() с /tauber-web/, без новых зависимостей. Все рабочие файлы внутри проекта. Числа паспортных характеристик не придумывать. Компоновочные чертежи не публиковать. Даты для человека ДД.ММ.ГГГГ. Закрытые исходные материалы не включать в публичную правку.

## Риски для проверки
- ПВКЖ не смешивается с авиакеросином в описаниях и полях подбора.
- Слитое топливо не возвращается в оборот автоматически после фильтрации.
- Б.7/Б.8 не представлены как стационарные установки.
- Все новые внутренние ссылки и перенаправление учитывают подпапку.
- Общие шаблоны сохраняют прежние страницы остальных категорий.
