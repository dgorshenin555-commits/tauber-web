# Обновление сайта Tauber: Vellum

## Согласованный результат
Перенести новый дизайн из `codex-vellum/Tauber-Vellum-Full.dc.html` в существующий Astro-сайт. Сохранить раздельные файлы содержания, адреса страниц и автоматическую публикацию GitHub Pages. Работа выполняется в отдельной ветке; результат — проверенный PR и локальный предпросмотр.

## Источник истины
Новый HTML — визуальный эталон. `Tauber-Vellum-Style.md` поясняет палитру и типографику; при расхождении приоритет у отображаемого HTML. Старый экспорт остаётся в истории и папке design. Новый экспорт сохраняется целиком в design/vellum, включая неизменённый runtime и все 189 изображений.

## Ограничения
Astro, статическая сборка, базовый путь `/tauber-web/`. Не заменять приложение iframe или runtime прототипа. Сохранить 10 категорий и 16 существующих товарных адресов, отдельные JSON для редактирования содержания. Не выдумывать технические характеристики. Не подключать серверную отправку заявок без настроенного адресата/сервиса; существующие почтовые запросы остаются рабочими.

## Оформление и поведение
Тёплая палитра #f0efe9 / #e8e6de / #322d2a / #8b8b8b, белые панели. Manrope 300/400 локально с кириллицей, существующие локальные Material Symbols. Без декоративных теней и цветных акцентов. Главная: три блока героя, 5×2 карточки на широком экране, отрасли и контактная панель. Шапка с белой навигационной капсулой и доступным боковым меню, светлый футер по HTML. Категории и товары получают те же цвета, типографику, большие скругления и оформление секций.

Сетки перестраиваются на 1280/768/390 px, без zoom и фиксированной ширины 1600px. Сохраняются навигация, галерея, аккордеоны, формы подбора и семантика клавиатурного управления. Если контент нового эталона отсутствует в JSON — переносить его в отдельные данные/секции, не удаляя существующую информацию.

## Проверка
Базовая сборка и тесты; после обновления полная сборка и тесты, сверка ссылок и ресурсов, визуальная проверка главной/категории/товара на 1280, 768, 390 px. Незавершённые информационные разделы исходного проекта не превращать в выдуманные страницы. Публикация основной версии только через проверенный PR.
